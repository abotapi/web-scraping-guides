# Web Scraping Guides

Short, practical guides on getting structured data out of well-known websites and industries: what fields exist, what to watch out for, and the options (official APIs, open data, DIY code, ready-made scrapers).

## How these guides work

Each guide covers the same ground: the data you can realistically get, the legal and etiquette notes, the options from do-it-yourself to no-code, and a small excerpt of the output shape. Excerpts are always mock data with made-up values.

Suggestions for a site or industry? Open an issue.
